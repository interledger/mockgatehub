MockGatehub Helm charts

A Helm repository, not a website. Point Helm at it rather than a browser.

helm repo add mockgatehub https://interledger.github.io/mockgatehub/
helm repo update
helm search repo mockgatehub --versions

The chart deploys MockGatehub — a mock of the GateHub API for development and testing — together with a single Valkey instance for state and webhook delivery. Chart version and application version are always the same number.
