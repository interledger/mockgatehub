# Changelog

All notable changes to this project will be documented in this file. See [Conventional Commits](https://conventionalcommits.org) for commit guidelines.

## [0.1.0](https://github.com/interledger/mockgatehub/releases/tag/v0.1.0) (2026-01-21)

### Features

* Initial release of MockGatehub
* Full Gatehub API mock implementation
* Multi-currency support (XRP, USD, EUR, GBP, ZAR, MXN, SGD, CAD, EGG, PEB, PKR)
* KYC flow with iframe-based form submission
* Webhook delivery system with HMAC signatures
* Dual storage backend (in-memory and Redis)
* Docker support with multi-platform builds (amd64/arm64)
* Pre-seeded test users for development
